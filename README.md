# anthonystoro.com

Personal portfolio and website for Anthony Storo.

## Status

**Design phase.** The next version of the site is being designed in Figma before production development begins.

Figma design: https://www.figma.com/design/FhpTHQ7jbsikAAxM3ETnvF/ANTHONY-STORO

## Planned workflow

1. Refine the website design and content in Figma.
2. Finalize responsive desktop and mobile layouts.
3. Prepare production assets and developer handoff.
4. Build the approved website in this repository.
5. Test accessibility, responsiveness, performance, and SEO.
6. Deploy the production site to Cloudflare.
7. Point anthonystoro.com to the new Cloudflare deployment after final approval.

## Repository structure

```text
assets/
  images/
  icons/
  logos/

```

The folders are reserved for the future production build. No production website code has been started yet.

## Deployment

The existing live website should remain untouched while the replacement is being designed and developed. DNS cutover will happen only after the new Cloudflare deployment is tested and approved.
